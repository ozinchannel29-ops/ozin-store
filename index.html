FAQ

Pertanyaan yang sering ditanyakan

Berapa lama website saya selesai?

Tergantung paketnya. Web store basic biasanya selesai dalam 2–4 hari kerja, website top up 5–10 hari kerja, dan sistem custom menyesuaikan jumlah fiturnya.

Apakah website top up bisa menerima pembayaran otomatis?

Bisa. Kami integrasikan dengan payment gateway, jadi pembeli bisa bayar via QRIS, e-wallet, dan virtual account, lalu pesanan diproses otomatis.

Apakah sudah termasuk domain dan hosting?

Ya. Paket Web Store Basic sudah termasuk domain .web.id, sedangkan paket Website Top Up sudah termasuk domain .com dan hosting gratis untuk tahun pertama.

Bisa request desain dengan tema game tertentu?

Tentu bisa. Desain bisa disesuaikan dengan tema game, warna brand, dan gaya yang kamu inginkan.

Berapa kali saya boleh revisi?

Semua paket mendapatkan revisi sampai selesai, selama masih dalam lingkup fitur yang sudah disepakati di awal.

Siap punya website gaming yang lebih profesional?

Konsultasi gratis, tanpa komitmen. Ceritakan dulu kebutuhanmu ke admin kami.
