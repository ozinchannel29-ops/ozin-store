# Ozin Store

Website jasa pembuatan website untuk bisnis gaming: website top up, web store game, website JB, dan sistem JB khusus.

Live: https://ozinweb.com

## Menjalankan di komputer

```
node server.js
```

Lalu buka http://localhost:3000.

## Struktur

Hanya isi folder `docs/` yang dipublikasikan ke ozinweb.com (GitHub Pages: branch `main`, folder `/docs`).

- `docs/index.html`: halaman utama
- `docs/style.css`: tampilan
- `docs/script.js`: menu HP, slider harga, tombol WhatsApp (nomor ada di baris paling atas)
- `docs/assets/`: logo dan screenshot portofolio
- `docs/CNAME`: domain untuk GitHub Pages
- `brand/logo-hd.png`: logo resolusi penuh (tidak dipublikasikan)
- `server.js`: server lokal untuk mencoba website di komputer (tidak dipublikasikan)
