# Ozin Store

Website jasa pembuatan website untuk bisnis gaming: website top up, web store game, website JB, dan sistem JB khusus.

Live: https://ozinweb.com

## Menjalankan di komputer

```
node server.js
```

Lalu buka http://localhost:3000.

## Struktur

- `index.html`: halaman utama
- `style.css`: tampilan
- `script.js`: menu HP, slider harga, tombol WhatsApp (nomor ada di baris paling atas)
- `assets/`: logo dan screenshot portofolio
- `CNAME`: domain untuk GitHub Pages
